# NZ Interactive Mathematics Workbooks

An interactive mathematics learning platform designed around the New Zealand Curriculum for Years 8–11.

The project transforms traditional mathematics workbooks into engaging browser-based learning experiences featuring guided problem solving, curriculum-aligned content, progress tracking, gamification, and tutor support tools.

---

## Overview

This repository contains a collection of standalone HTML applications designed to help students strengthen mathematical understanding through active participation rather than passive worksheet completion.

Each workbook provides:

- Interactive exercises
- Guided step-by-step problem solving
- Progress tracking
- Achievement and reward systems
- Tutor and teacher support tools
- Visual learning aids
- Self-paced learning workflows
- Browser-based access without installation

Everything runs entirely in the browser using HTML, CSS, and JavaScript.

## Key Features

### Interactive Learning

Students engage directly with mathematical concepts rather than simply viewing answers.

Features include:

- Multi-step solutions
- Guided question workflows
- Immediate feedback
- Progressive learning paths
- Interactive answer validation

---

### Curriculum Alignment

The workbooks are organised according to New Zealand Mathematics curriculum strands and learning outcomes.

Topics are structured to support:

- Number and Algebra
- Geometry and Measurement
- Statistics
- Probability
- Mathematical Thinking
- Problem Solving

---

### Gamification System

The platform includes motivation features designed to encourage practice and persistence.

Examples include:

- Achievement tracking
- Star systems
- Learning streaks
- Progress indicators
- Completion rewards
- Performance statistics

---

### Progress Tracking

Students can monitor their learning through:

- Question completion tracking
- Progress bars
- Workbook navigation panels
- Session statistics
- Activity summaries

---

### Guided Problem Solving

Many activities use scaffolded learning techniques including:

- Step-by-step progression
- Visual cues
- Structured solution paths
- Answer verification
- Reflection opportunities

These features support students who require additional guidance while still promoting independent thinking.

- Tutor management panels

### Visual Mathematics Support

## Educational Philosophy

This project is built around the idea that mathematics learning should be:

- Interactive
- Accessible
- Engaging
- Scaffolded
- Curriculum-focused
- Suitable for independent practice
- Useful for classroom support

Rather than providing simple answer sheets, these workbooks encourage students to explore concepts, develop reasoning skills, and build confidence through guided practice.
